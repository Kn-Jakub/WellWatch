# 0001 — Record architecture decisions

**Status:** Accepted · **Date:** 2026-10-30

## Context
WellWatch is a solo project, but it is also a portfolio piece. In a year (or in an interview) I need to explain *why* it is built the way it is, not only *what* it does.

## Decision
Every significant decision gets a short ADR in this folder: `NNNN-title.md` with **Status, Context, Decision, Consequences**. ADRs are never rewritten — a changed decision gets a new ADR that *supersedes* the old one.

## Consequences
- ~10 minutes per decision.
- The README can link here instead of explaining every choice.
- Until the GitHub repo exists, ADRs live in the vault; then they move to `docs/adr/` in the repo and the vault only links to them.
